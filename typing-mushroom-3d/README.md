# 無限高湯討伐隊 3D（第一人稱）

`game-mushroom` 的第一人稱 3D 重製版。整個畫面就是 3D 遊戲世界：你站在料理台前，手持湯杓砲，每輸入一個正確字元就發射一次；蘑菇在前方，買來的設備排在兩側一起開火。所有介面都是浮在場景上的遊戲 HUD。依 `game-mushroom/GAME_DESIGN_SPEC_3D.md` 承接全部玩法。

## 畫面配置

| 位置 | 內容 |
| --- | --- |
| 上方 | 菇幣、金湯滴、英打每字傷害、自動火力；地區／採集深度選單；視角回正、說明、設定 |
| 左上 | 生效中的效果（道具、連擊、閉眼連打、冰晶減速…） |
| 中上 | 菇王戰：大血條、護盾標籤、英打連擊、破盾門檻、機制說明 |
| 右側 | 選單列：設備、升級、道具、裝備、圖鑑、成就、統計（寬螢幕可把面板釘選在右側，3D 鏡頭會自動讓開） |
| 下方 | 挑戰菇王按鈕（顯示進度、可挑戰時發光）、破盾／解凍按鈕、英打主控台 |

手機版同樣全螢幕：選單改為底部滑出面板；軟鍵盤彈出時英打主控台會自動移到鍵盤上方。

原生 HTML / CSS / JavaScript，沒有建置流程；3D 使用本地放置的 Three.js r160（`vendor/three.module.min.js`，MIT 授權見 `vendor/three.LICENSE`），不連外部 CDN。介面圖示使用 Material Design Icons（MDI v7.4.47），需要的路徑收在 `js/icons.js`（授權見 `vendor/mdi.LICENSE`）。所有模型、貼圖都是程式產生，沒有音效。

## 啟動

在專案根目錄啟動靜態伺服器（ES module 需要 http）：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8768/typing-mushroom-3d/>。網址加上 `?flat` 會改用 2D 戰場（給效能較弱的裝置）；裝置不支援 WebGL 時也會自動退回 2D，所有機制照常運作。

## 操作

- **英打攻擊**：直接打字即可（不必先點輸入框），每個正確字元（字母、空格、標點）攻擊一次，字母不分大小寫。
- **環視**：在場景上拖曳（滑鼠或手指）；右上角準星可回正，放著幾秒也會自動回正。字母鍵全部留給英打，因此不用 WASD 移動。
- **指定目標**：點蘑菇本體或頭上的名牌（名牌是按鈕，也能用鍵盤操作）。點擊只指定目標，不造成攻擊。
- **破盾／解凍**：按住按鈕 2 秒（滑鼠、觸控、Space／Enter）；急凍菇戰中也可以直接在 3D 場景按住結冰的設備 2 秒解凍。

## 架構

| 層 | 檔案 | 說明 |
| --- | --- | --- |
| 遊戲狀態 | `js/config.js`、`content.js`、`combat.js`、`game.js`、`storage.js`、`format.js` | 沿用原版，不依賴 DOM。只做兩處小改：`storage.js` 可指定存檔鍵；`game.js` 多發一個只供畫面使用的 `deviceFire` 事件 |
| 英打規則 | `js/typing.js` | 從原版 `main.js` 抽出的逐字判定、幸運、瘋狂連打、閉眼連打與跳題，不依賴 DOM |
| 介面 | `index.html`、`css/game.css`、`js/hud.js`、`js/app.js` | 全螢幕遊戲 HUD、英打主控台、滑出／釘選式管理面板、存檔與對話框；`hud.js` 會把 HUD 遮住的範圍告訴 3D 鏡頭，讓戰場置中在可視區；保留 2D 戰場作為備援 |
| 3D 呈現 | `js/scene/index.js`、`env.js`、`actors.js`、`fx.js`、`labels.js` | 第一人稱鏡頭、三個地區場景、蘑菇／菇王／設備／外送員模型、粒子與名牌。只讀取狀態與事件，不回寫任何數值 |
| 題庫 | `js/typing-prompts.js`、`js/typing-vocab.js` | 沿用原版 |

## 存檔

- 3D 版使用獨立存檔鍵 `tools.mushroom3d.*`，不會改動原版進度。
- 第一次開啟時若偵測到原版（2D）存檔，會詢問是否匯入；之後也能在「設定 → 匯入原版（2D）進度」再次匯入（會先自動備份）。
- 匯出字串與原版格式相同，兩邊可以互相匯入。

## 測試

```bash
node tests/run-node.js
```

`tests/typing-suite.js` 驗證英打規則（逐字攻擊、幸運、瘋狂連打、閉眼連打、菇王連擊、破盾門檻、題庫筆數）。`tests/suite.js` 為原版測試，原封不動複製；其中 11 項在原版資料夾中同樣失敗（測試早於目前的菇王門檻與平衡數值），並非 3D 版造成。
