# 高湯遠征 · 3D 英打冒險

獨立放在專案根目錄的第一人稱 3D 重製版。固定鏡頭，玩家持續打字攻擊；點選蘑菇可指定單體設備優先目標。介面由全畫面戰場、浮動打字操作台、遠征手冊與戰報構成。

正式遊玩：[GitHub Pages](https://ml-yoyohuang.github.io/tools/game-mushroom-3d/)。

## 開啟

可以直接開啟 `index.html`。也可在這個資料夾啟動僅服務遊戲的本機伺服器：

```bash
cd game-mushroom-3d
python3 -m http.server 8768 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8768/>。全站使用本機 HTML / CSS / JavaScript 與原生 WebGL，不需安裝套件、建置、CDN 或遠端字型，沒有音效。

## 操作與內容

- 開場是獨立的 3D 蘑菇迎賓場景；新玩家「開始遠征」，有存檔時「繼續遠征」並顯示地區與進度。按 Enter 可出發，主選單也能開啟玩法與設定。遊戲左上標誌或設定中的按鈕可返回標題並存檔。
- 主選單不啟動戰鬥迴圈；離線收益在進場時才結算。標題場景使用獨立模型，不改變實際敵人或存檔。
- 逐字輸入英文；每個正確字母、空格、標點各攻擊一次，大小寫皆可。支援實體鍵盤、IME 英文鍵值、手機軟鍵盤。
- 單字右側眼睛按鈕切換閉眼模式。已輸入字元保持可見；每 10 個連續正確字元 +5% 傷害，上限 +25%，3 秒未正確輸入或睜眼、跳過、錯字時重置。
- 右側選單開啟整備、圖鑑、成就與戰報。遠征手冊包含設備、升級、補給、裝備、蘑菇圖鑑、A–Z 單字筆記與成就。
- 三個地區、七種普通蘑菇、三隻菇王、八種設備、二十五項升級、四種道具、六件裝備，以及完整初級／中級／句子題庫。
- 豆腐菇：每層須蓄滿 2 秒後放開，第二／三層須先完成 3／5 個單字。急凍菇：凍結設備後，按住設備 2 秒解凍。支援滑鼠、觸控與 Space／Enter。
- 手機戰場固定 320px，打字操作台維持一般頁面配置。

## 立體模型

`js/models3d.js` 建立有頂點、三角面與法線的立體模型，`3d.js` 使用 WebGL 光照與透視即時繪製：

- 七種普通蘑菇各有造型；岩殼、海綿、冰晶、寶箱、金色變種有獨立部件。
- 杏鮑菇、百葉豆腐菇與急凍菇有獨立菇王模型。
- 木砧板廚房、沸騰鐵鍋、冰箱內部是不同的立體場景。
- 外送員使用便當袋、提把與小型搬運菇模型。

實際使用的模型另匯出為 [`models/`](models/) 裡的 14 組 OBJ / MTL，供 Blender 等工具開啟；頂點與面數記錄於 `models/manifest.json`。執行 `node tools/export-models.js` 可由同一份幾何資料重新匯出。

## 存檔

3D 版使用 `tools.mushroom3d.*` 獨立存檔鍵。設定提供手動存檔、備份、還原、匯出、匯入及「承接原版進度」。若瀏覽器的檔案來源隔離使原版存檔無法直接讀取，可在原版匯出 MUSH1 字串，再匯入 3D 版。匯入前會備份，不會寫入原版的存檔鍵。

支援舊原版格式及上一版 3D 原始 snapshot 的遷移；使用本機心跳鎖避免多分頁同時寫入。離線結算報告明確標示時間上限、60% 效率、估算擊敗數及不包含的內容。

## 架構與驗證

- `index.html`、`css/expedition.css`、`js/interface.js`：全新遊戲介面。
- `css/title-screen.css`、`js/title-screen.js`：響應式標題、開始／繼續與進度摘要。
- `js/main.js`：逐字輸入、進度、存檔與操作協調。
- `js/game.js`、`js/combat.js`：遊戲狀態與計算；3D 動畫不決定遊戲結果。
- `js/models3d.js`、`3d.js`：模型、場景、固定第一人稱鏡頭、光照與事件回饋。

```bash
node tests/run-node.js
```

完整規格對照與實際驗證範圍見 [`docs/SPEC_AUDIT.md`](docs/SPEC_AUDIT.md)。原規格保留於 `GAME_DESIGN_SPEC_3D.md`。

目前共 110 項自動測試通過；桌機與 375×812 手機版標題、首次開始、繼續、返回、玩法與設定已在瀏覽器操作驗證。
