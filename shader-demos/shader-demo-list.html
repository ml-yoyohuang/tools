SHADER DEMOS

十六種畫面的質地

每一頁都是一支即時運算的 shader：沒有任何外部圖片、字型或函式庫，所有畫面都由數學在你的顯示卡上當場生出來。前九頁談手法，後七頁談媒材——紙、墨、藥水、玻璃與布，如何被翻譯成程式。

效果系列　EFFECTS

顆粒漸層網格01

這個畫面像一張放了很久的紙，顏色在上面慢慢地互相滲透，誰也沒有贏。

安靜・印刷感・耐看
網站首屏背景、品牌色票的動態展示、文章封面底圖——任何需要安靜底色又不想用一張 JPG 的地方。
雜訊溶解02

這個畫面像兩段底片在同一格上打架，誰也沒有完全輸掉，中間燒出一道金色的邊。

電影感・敘事・轉場
頁面切換、作品集的前後對比、影片開頭的標題卡；把速度調到 0 就變成可用游標手動刷過的互動。
液態位移03

這個畫面像一池很淺的水，你的游標是手指，它會記得你剛剛摸過哪裡。

觸感・有生命・回應
作品集的主視覺、產品照的互動容器、需要「這個網站有在呼吸」的著陸頁。手機上用手指拖曳。
抖動與網點04

這個畫面像一張被影印了太多次的人像，它放棄了所有灰階，只剩下有墨和沒墨兩種意見。

復古印刷・有態度・兩色
人像作品集、音樂與活動海報、需要強烈平面感的編輯型頁面；兩色輸出也很適合做 CSS 之外的 hero 圖。
域扭曲雜訊05

這個畫面像一塊正在流動的石頭，它比你有耐心得多。

有機・大理石・緩慢
大面積的版面底紋、產品材質的示意、需要「天然但不具象」的背景；靜止時也完全成立。
回饋殘影06

這個畫面像一個記性不好的房間，你離開以後它還會把你的樣子留著一陣子，只是每一刻都記得更模糊一點。

夢境・時間・遲滯
音樂或影像類的網站背景、載入中的過場、互動裝置；它會獎勵停留久一點的訪客。
反應擴散07

這個畫面像一塊從來沒有人見過的骨頭，它正在用兩種互相追殺的化學物質把自己長出來。

生物・會長・珊瑚
科學或醫療品牌的視覺、生成式藝術的輸出、需要「這東西是活的」的展示頁。在畫面上按住拖曳可以播種。
像素排序08

這個畫面像一張正在被強迫整理的照片，有人逼它把所有顏色按亮度排好，而它一直排不完。

故障・銳利・數位
科技或音樂品牌的主視覺、404 與維護頁、需要一點不服從感的地方。
光線步進雕塑09

這個畫面像一件沒有人動手捏過的陶器，它只是幾個距離公式談好了要在哪裡融在一起。

立體・陶土・數學
產品或建築事務所的首屏、3D 感的裝飾區塊、不想載入任何模型檔的立體視覺。

媒材系列　MATERIALS

暗房顯影與曝光反轉10

這個畫面像一張泡在顯影液裡的相紙，影像正從紙底浮上來，而且有人故意在中途開了一次燈。

銀鹽・等待・反轉
攝影師或藝廊的網站、紀錄片的章節頁、任何想談「時間」與「過程」的內容。拖動顯影時間可以看它整段浮現。
Risograph 絹印11

這個畫面像一張剛從孔版印刷機吐出來的海報，兩個色版沒有對準，而那正是你喜歡它的原因。

螢光・套色歪・紙感
活動海報、獨立刊物與唱片的網站、年度回顧頁；配色本身就很有主張，少用其他顏色。
藍曬12

這個畫面像一張被太陽曬了二十分鐘的水彩紙，上面躺過一把草，而刷藥水的人手並不穩。

普魯士藍・植物・手工
植物、香氛、手作或永續品牌的頁面、食譜與自然書寫的章節圖；它天生就帶著安靜與老派。
玻璃與折射13

這個畫面像有人在你和風景之間放了幾片厚薄不一的玻璃，邊緣都滲出一點彩虹。

清透・色散・光學
產品頁的玻璃質感容器、金融或科技品牌的乾淨主視覺、相簿與圖庫的覆蓋層。
生長與菌落14

這個畫面像一塊放在戶外太久的石頭，上面的東西正在往外長，中間的部分已經開始死了。

地衣・年輪・擴張
環境、科學或材料類的主題頁、長時間展示的裝置畫面；它永遠不會停在同一個狀態。在畫面上按住可以播種。
長時間曝光15

這個畫面像一張快門忘了關的夜景，所有移動過的光都還留在底片上，誰也沒有離開過。

夜・光軌・累積
夜間活動、音樂現場、交通或物流主題的首屏；也很適合當作深色模式的頁首。把游標移過去會留下自己的軌跡。
織品與摩爾紋16

這個畫面像兩塊疊在一起的紗，角度差了一點點，於是從它們中間浮出一層誰也沒有織過的花樣。

靛藍・平織・干涉
織品、服飾、家具或工藝品牌的背景、材質庫的封面；角度調到接近 0 時會變成安靜的素色布紋。
