# 無限高湯討伐隊

受「打蘑菇」玩法啟發的純網頁放置／點擊遊戲。原生 HTML / CSS / JavaScript，**零執行時依賴**、沒有建置流程、不連外部 CDN 或遠端字型、**沒有任何音效或音訊資源**（企劃中的喀喀聲、硬幣聲等全部改成視覺回饋）。

世界觀、名稱、文案、數值與圖片皆為原創，未使用任何既有遊戲的角色、素材或程式。

目前所有圖片都是本地產生的 SVG 占位圖，可直接替換（見「換圖指南」）。

## 啟動方式

請以 http 開啟。在專案根目錄：

```bash
python -m http.server 8768 --bind 127.0.0.1
```

接著開 <http://127.0.0.1:8768/game-mushroom/>。

整個資料夾就是可部署的靜態網站，複製到任何靜態主機即可，所有資源都是相對路徑。

## 計算管線

```
手動點擊傷害 = (基礎點擊 + 升級絕對值)
             × 暴擊乘區      （機率觸發，明確倍率）
             × 連擊乘區      （層數上限明確）
             × 提神飲料乘區
             × 軟化乘區      （只對點擊，獨立乘區 ×2）
             × 全域乘區      （火力全開、宇宙護照）

設備單次傷害 = 設備基礎傷害
             × 設備傷害乘區  （鈦合金、廚師高帽）
             × 專屬協同乘區  （辛香料風暴、軟硬兼施…）
             × 電磁爐乘區    （有界，上限 ×3）
             × 無情機器乘區  （以不含自身加成的基準輸出判定）
             × 全域乘區
```

岩殼在所有乘區算完**之後**才判定：單次傷害低於該地區門檻時強制變成 1。真實傷害穿透岩殼但不穿透菇王護盾。所有協同一律讀**設備數量**，不讀其他設備的最終產量，因此沒有循環。

**收益**：以**實際有效傷害**計算（過量傷害不計），且每個目標的掉錢預算上限 = 最大血量，回血不補預算。擊敗另外給保底獎勵。

## 時間、離線與存檔

每次結算都把 `lastSettle` 推進到現在，**同一段時間只會被結算一次**，不可能靠切換分頁重複領取。

| 間隔 | 處理方式 |
| --- | --- |
| ≤ 60 秒 | 正常遊玩，以固定 100ms 步長推進（含限時倍率） |
| > 60 秒 | 離線模型結算 |

離線模型是**封閉式估算**（不逐次模擬每一次攻擊，一年的間隔也在數毫秒內算完）：

```
每秒擊敗數 = min(DPS ÷ 平均血量, 每秒上限 6)
有效 DPS   = 每秒擊敗數 × 平均血量        ← 受生成速度限制，過剩輸出不計
每秒菇幣   = 有效 DPS × 傷害掉錢 + 每秒擊敗數 × 平均獎勵
總收益     = 每秒菇幣 × 秒數 × 60% 效率 × 裝備加成
```

規則：只採集**目前所在地區**的普通蘑菇；不推進菇王、不開新地區、不生成可點擊事件；**不計入任何限時倍率**；**不發放稀有掉落**（寶箱與純金菇排除在平均值外）；報告中的擊敗數**標示為估算**。上限 4 小時，買下「複合利息」後 12 小時。系統時間倒退時不給負收益。

存檔：每 20 秒自動保存，另有手動存檔、建立備份、還原備份、匯出、匯入與清除確認。讀取前驗證結構與數值；未知 ID 忽略而不是整份拒絕；支援 v1→v2 遷移；匯入失敗絕不覆寫原存檔（成功匯入前會先自動備份）。多分頁以 localStorage 心跳鎖協調，只有一個分頁會更新遊戲與寫入，其餘顯示提示並可手動接管。**這是避免互相覆寫的保護，不是防作弊機制。**

## 換圖指南

1. 占位圖都在 `assets/`，檔名對應設定表：
   - 蘑菇 `mush-01.svg` ～ `mush-07.svg`
   - 菇王 `boss-01.svg` ～ `boss-03.svg`
   - 設備 `device-01.svg` ～ `device-08.svg`
   - 道具 `item-01.svg` ～ `item-04.svg`、裝備 `equip-01.svg` ～ `equip-06.svg`
   - 升級 `upgrade-<升級ID>.svg`、外送員 `courier.svg`
2. 直接覆蓋同名檔案即可，SVG 或 PNG 都行，支援透明背景。
3. 要換路徑或檔名，改 `js/config.js` 與 `js/content.js` 的 `image` 欄位。
4. 圖片以 `object-fit: contain` 呈現，自動保持長寬比並置中。
5. 任何一張載入失敗，該項目自動改用色塊與名稱縮寫，遊戲照常運作並出現提示。
6. 新增內容後重新產生占位圖：`node tools/make-dummy-art.js`。

> SVG 是嚴格的 XML，同一元素出現重複屬性會整張解析失敗。
