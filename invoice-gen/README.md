# 隨身一張 · 載具桌布製作器

純前端 HTML / CSS / JavaScript 工具。圖片與載具號碼只在裝置內合成，沒有後端、第三方 CDN、分析追蹤或線上載具驗證。無需安裝套件或建置。

## 開啟方式

建議從專案根目錄啟動靜態伺服器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765/invoice-gen/`。專案根目錄工具集也已加入入口。

亦設計成可以直接開啟 `index.html`；初始圖庫使用內嵌 SVG data URL，避免讀取本機圖片時污染 Canvas。各瀏覽器對本機檔案下載、分享、儲存的支援不同，以 HTTP / HTTPS 開啟較穩定。若要在手機使用，可部署到原本的靜態網站；程式不會自行部署。

## 功能

### 手機簡易製作

`wizard.html` 提供三個獨立畫面：載具號碼 → 選擇版型與形狀 → 圖片。原本的 `index.html` 頂部已加入「簡易製作」連結。

畫布以螢幕可容納的最大比例顯示，設定只在點選 SVG 圖示後從底部浮出，可用關閉按鈕或拖拉握柄向下收合。圖片可拖曳及雙指縮放，點選條碼後可移動條碼；方向鍵為 1 個輸出像素，Shift 為 10 像素。自訂比例時才顯示拖拉控制點。返回前一步保留目前設定。

簡易版圖片圖庫的第一格固定為「自選圖片」，點選即開啟相簿或檔案選擇器，不另設圖片來源分頁。色票與十四款 SVG 圖樣收在五組圖庫入口：流動的波浪（均勻波浪、波浪）、方格與立方（格子、雙色格子、立方體方塊）、斜向節奏（斜線、寬斜線）、圓形拼貼（點點、相切點點、四分之一圓、四分之一圓拼貼）、自由曲線（彎彎曲線、不規則曲線 · 夜色、不規則曲線 · 暖紙）。每款均有異色版；重複點選同一入口依序輪換圖樣與配色，保留畫布上的縮放與位置。流動的波浪由白底橘線的均勻波浪起始。圖庫另有貓、狗與 Unit-β 的直橫式插畫，採用小圖預覽、選用時才載入完整 JPG。儲存時依尺寸輸出 PNG 或印刷 JPG，支援裝置上可使用系統分享。

驗收頁：`/invoice-gen/tests/wizard.html`。檢查項目包含三步驟流程、只有當前工具可見、返回保留設定、圖片讀取、插畫的直橫式選用、實際 PNG／JPG、1595 × 2540 px 與 JFIF 750 dpi，以及 320／390／768 px 無水平溢出。實體手機的觸控與相簿分享仍待實機確認。

共用 JPG 密度寫入已修正 JFIF 欄位偏移，沒有 JFIF 的有效 JPEG 亦會補上密度紀錄；原編輯器的下載與分享格式標示也已對應實際 MIME 類型。

### 完整編輯器

- 操作步驟依序為：輸入載具 → 選擇版型與調整樣式 → 決定畫布形狀 → 選擇圖片。
- 預設使用「自選圖片」，不會自動套用內建圖片。內建圖庫顯示五組 SVG 圖樣，沒有分類篩選；再次點選同一組輪流切換圖案與配色。
- 本機選圖與拖放上傳；支援瀏覽器能解碼的 JPG / PNG / WebP / AVIF / GIF。GIF 以靜態圖片處理。HEIC / HEIF 若無法解碼會提示轉檔。
- 單張檔案 30 MB 上限；超過 4096 px 長邊的圖片讀取後先降採樣，減少編輯時的記憶體負擔。
- 載具格式整理與檢查：`/` 加 7 碼 `[0-9A-Z.+-]`。小寫、全形輸入會正規化；不猜測 `O/0` 或 `I/1`。
- 手機桌面、原圖比例、直式 2:3、橫式 3:2、正方形、自訂比例。
- 自訂比例可輸入數字、交換寬高、拖拉八個控制點、常用比例吸附、重置。Pointer Events 共用滑鼠與觸控路徑。
- 「移動圖片」「移動條碼」「調整比例」三種編輯模式。圖片與條碼方向鍵每次移動 **1 個輸出像素**，Shift＋方向鍵為 10 px；比例模式則以輸出像素為基準改變寬高比，輸出解析度仍自動計算。
- 滿版、下方留白、完整圖片、左右分欄版型。先選左右分欄時會自動採用橫式畫布；後續改成寬高比 < 1.2 的畫布時轉為下方留白版型。
- 圖片平移、縮放、90° 旋轉與重置；底色、條碼卡片大小、圓角、小標題與快捷位置。
- 畫板內支援滑鼠拖曳、滾輪縮放、雙指捏合縮放與雙指平移。放開一指後可接續單指拖曳；縮放以游標或雙指中點為基準。
- 畫板也有＋／−縮放按鈕；聚焦畫板後可用鍵盤＋／−。填滿模式縮放 100–400%，完整顯示模式 25–400%。
- 圖片與條碼拖曳可吸附畫布中心、安全邊界、版型分區與另一物件的邊緣／中心，吸附範圍為 6 個預覽像素。對齊參考線只在畫板顯示，不寫入 PNG。
- 可取消「吸附對齊參考線」，或按住 Alt 暫停吸附；方向鍵保持精準步進，不會被磁吸拉回，精確對齊時仍顯示參考線。
- 手機鎖定畫面／主畫面示意圖層，**不會輸出**到 PNG。
- PNG 匯出、原圖連結、支援裝置上的系統檔案分享、可選的純條碼備用卡。
- 號碼預設不保存；使用者勾選才寫入 localStorage，亦可清除。不把載具號碼放到下載檔名或 URL。

## 輸出與掃描限制

- 一般輸出長邊 1800 px，依比例計算另一邊。手機選項使用指定解析度；裝置估算限制長邊 1800–3200 px。
- 自訂寬高比限制在 0.42–2.4。極端原圖會改以底色補滿安全畫布，保留照片內容；畫面會說明比例調整。
- Code 39 黑線白底、不加可選 checksum，起訖符號由編碼器處理。左右至少保留 10 個窄模組的靜區，窄線以整數像素繪製，至少 2 px。
- 卡片保持足夠寬度及留白，不允許條碼變形或超出畫布。
- 匯出後重新開啟實際 PNG，在三條掃描列讀取黑白像素，解碼比對輸入。這是輸出完整性檢查，使用同一份 Code 39 字元表，**不能代替獨立解碼器或實體掃描驗收**。
- 格式檢查不代表載具存在、已申請或屬於使用者。尚未輸入有效號碼時顯示不可匯出的示意條碼。
- 提高輸出解析度不會放大手機上的實際條碼尺寸。使用時應確認未被系統裁切、模糊、App 圖示、通知遮擋，並實際試掃。

## 悠遊卡印刷尺寸

依悠遊卡官方「標準卡圖像條件」，卡面 8.6 × 5.4 cm、300 dpi 以上、RGB JPG，並接受 **300 KB 以上 JPG 或 400 萬畫素以上數位圖檔**。為增加印刷細節，採用 300 dpi 換算尺寸的 **2.5 倍線性尺寸**：直式輸出 **1595 × 2540 px（4,051,300 畫素）**，橫式輸出 **2540 × 1595 px（4,051,300 畫素）**。JFIF 標示 750 dpi，約對應卡面實際尺寸 5.4 × 8.6 cm。Canvas 匯出 RGB JPEG，寫入 JFIF dpi 密度值。互動畫板使用縮小預覽以維持操作效能；匯出檔以完整 4 百萬畫素繪製。

因此卡面 JPG 即使小於 300 KB，仍符合官方列出的 400 萬畫素數位圖檔選項。匯出卡片會顯示檔案大小與實際畫素數。印前另請確認悠遊卡商家對出血、裁切及可接受內容的要求。

悠遊卡官方規格：[企業商品－標準卡圖像條件](https://www.easycard.com.tw/business)。

## 檔案結構與正式圖替換

| 檔案 | 職責 |
| --- | --- |
| `index.html` | 語意化 UI 與控制項 |
| `style.css` | 紙質感介面與響應式樣式 |
| `gallery.js` | 圖庫資料與內嵌 SVG 圖樣 |
| `artworks/`、`thumbs/` | 直橫式插畫原圖與輕量圖庫縮圖 |
| `favicon.svg`、`favicon-32.png`、`apple-touch-icon.png` | 網站圖示 |
| `og-home.png`、`og-wizard.png` | 首頁與簡易製作頁各自的社群分享圖（1200 × 630） |
| `tools/generate-social-assets.swift` | 在 `invoice-gen/` 執行 `swift tools/generate-social-assets.swift` 重新產生 PNG 圖示與分享圖 |
| `core.js` | 比例、尺寸、圖片幾何、縮放基準、吸附計算、條碼卡片邊界、Code 39 繪製與像素讀取 |
| `app.js` | 圖片載入、Canvas 合成、互動、儲存與分享 |
| `tests/core.test.cjs` | 無外部依賴的離線核心測試與 PNG 測試圖產生 |
| `tests/browser.html` | 實際瀏覽器中的操作、上傳、匯出、響應式驗收 |
| `tests/vision-check.swift` | macOS Apple Vision 獨立 Code 39 解碼驗收 |

正式插畫準備好後，修改 `gallery.js` 的圖庫資料，保留 `id`、`name`、`category`、`color`，將 `src` 指向同站台圖片。使用外部圖片必須具備適當 CORS；不要任意加入外站圖片服務。若仍要支援直接開啟 HTML，正式圖也需內嵌 data URL，或由使用者透過本機上傳。

## 驗收

```sh
node invoice-gen/tests/core.test.cjs /tmp/invoice-gen-fixtures
```

測試涵蓋合法／不合法輸入、相似字元不改寫、輸出尺寸、卡片邊界、極端比例、條碼靜區、三列像素讀回、損壞偵測，並產生涵蓋全部合法字元的 PNG 供獨立掃描器檢查。

macOS 可再執行：

```sh
swift -module-cache-path /tmp/invoice-swift-cache invoice-gen/tests/vision-check.swift /tmp/invoice-gen-fixtures/manifest.json
```

啟動 HTTP 伺服器後，開啟 `/invoice-gen/tests/browser.html`，按「執行瀏覽器測試」。測試不下載檔案，會保留並恢復測試前的載具儲存值。

仍需人工驗收：

1. 桌面滑鼠拖曳圖片、卡片、八個比例控制點；確認切換模式不誤移其他物件。
2. 實體手機測試手指拖曳、頁面捲動、相簿選圖、長按原圖儲存與系統分享。
3. 在相簿、鎖定畫面、主畫面分別顯示輸出圖片，以獨立掃描器及店家設備試掃。
4. 在 Safari / Chrome 確認上傳照片方向、各版型裁切與 PNG 品質。

目前執行紀錄（2026-10-26）：

- 核心離線測試 **1010 項 assertions 通過**。
- 使用本機 HTTP 頁面完成 **51 項瀏覽器驗收**，包含預設選圖及步驟順序、滾輪縮放、雙指事件、接續單指拖曳、圖片／條碼吸附參考線、Alt 暫停吸附、1 px / 10 px 精準位移、圖片上傳、旋轉、尺寸、版型、實際 PNG 匯出後解碼、320 / 390 / 768 / 1200 px 水平溢出檢查。
- 雙指部分測試使用合成 PointerEvent 串流，已驗證處理邏輯，但不能代替實體手機觸控驗收。另以實際滑鼠拖曳確認圖片吸附時參考線可見。
- 實際檢視桌面 1440 px、手機 390 px 的畫面；以滑鼠拖曳比例控制點，確認比例與輸出尺寸同步改變。
- 手機寬度下的儲存視窗可顯示成品及備用卡，合成 PNG 已實際下載成功。測試使用 `/ABC+123` 範例號碼，不應拿來當作自己的載具。
- 實體手機觸控、iOS / Android 的相簿儲存與系統分享、店家設備試掃仍需人工驗收。
- Apple Vision 獨立掃描測試受環境的像素緩衝區建立失敗阻擋，**尚未通過獨立解碼器驗收**。不要把頁面內的自我解碼檢查等同於所有實體設備可掃描。
