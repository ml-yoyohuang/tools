# 貼紙專案檔

每個檔案都是 Pixel Workshop 專案，用「載入專案」開啟。
改完按「儲存專案」，把檔案放進 `_incoming-assets/`，再說是哪一張。

## 修改前請注意

有些貼紙在相機裡是程式產生的。手修並放回相機後，會變成一格一格寫死的圖。

**圖案貼紙：可以放心改**

月亮、雲、小行星、光束、平底鍋、茶壺、隔熱手套、問號、驚嘆號、ZZZ、愛心眼、生氣、閃亮亮。

這些原本用公式畫出來。改過以後使用上沒有差別，只是不能再靠改程式裡的數字整張重算，例如把月亮放大。

**文字貼紙：改之前想一下**

- 辦公字：UNKNOWN、SUSPECT!、WE KNOW、ORIGINAL、SAMPLE、FRAGILE、SOLD OUT、BACK SOON
- 拍貼字：BFF、BEST FRIENDS、LOVE、SO CUTE、IDOL、SUPER STAR、NO. 1、HAPPY、FOREVER、PEACE、OMG、SMILE

這些是「文字 + 樣式」組合出來的，現在換字或換顏色只要改一個詞。手修放回相機後就變成固定的圖，之後要換字得重畫，或從 git 歷史找回程式版（手修的部分會不見）。

- 之後可能還會換字的，先不要手修。
- 字已經定案、只想修筆畫或花邊的，可以手修。

**半透明的地方**

腮紅、三角尺、光束、鮟鱇魚的燈籠光暈有半透明的顏色。編輯器裡會畫成實心，放回相機時要說哪個顏色要轉回半透明。

**日期貼紙**

每天自動顯示當天日期，不在這裡，也不能手修。
