# INK INK｜印印｜設計方向文件

> 這份文件記錄專案的核心決定。每次開始新的工作前，請先讀完這份文件，所有實作都要符合這裡的方向。

## 專案目標

做一個網頁版的絹印體驗。重點不在教學或寫實模擬，而是讓人感受到「第一次走進絹印工作室」的新鮮與興奮：看到滿牆的墨水、拿到自己的版、親手刮印，最後掀開網框看見成品。

專案名稱：INK INK｜印印。不使用任何真實店家的名稱或標誌。

## 核心原則

1. **「親臨現場」的感覺來自流程和手感，不來自畫面寫實。**
   不做 3D 場景，也不做擬物風格的道具。墨水罐就是一張張顏色卡片，網框就是一個框起來的區塊，刮板就是一個可以拖動的條狀元件。
2. **UI 俐落，成品不完美。**
   介面是乾淨的 2D 網站排版：卡片、格線、清楚的字體層級和細緻的互動回饋。只有「印出來的成品」帶有手工的不完美，兩者形成對比。
3. **瑕疵來自使用者的操作。**
   錯位是使用者自己對出來的，飛白是刮太快造成的。瑕疵不是隨機套上的濾鏡，而是操作的結果，讓每張作品都獨一無二。

## 成品質感規格（輕微手感）

整體感覺接近 Risograph 印刷：色塊平整乾淨，帶有輕微的手工痕跡。

- **基礎質感**（每次都有，程度輕）：
  - 邊緣微微抖動，約 1–2px。
  - 零星的飛白點，約 5% 的面積。
  - 偶爾出現細細的橫向刮痕。
- **疊色**：各層以色彩相乘（multiply）的方式疊合，重疊處自然變深。
- **較重的效果只在特定條件下出現**：
  - 刮太快：該段出現明顯飛白。
  - 刮太慢或重複刮：墨水溢出邊緣。
  - 沒刮到的區域：缺墨。
  - 墨還沒乾就印下一層：糊開、沾染。
  - 拖太久沒印：塞網，局部印不出來。
  - 布料類材質：淡淡的織紋。
- **避免**：重度擬真的紋理，以及看起來像照片的效果。

## 平台

- 以桌機為主（1280px 以上），手機做基本的 RWD 即可。
- 技術以 HTML、CSS、JavaScript 加上 Canvas 2D 為主，不使用 3D。

## 完整體驗流程

1. **入口**
   - 一面墨水卡片牆，顏色多、配色協調，像在逛色票本。
   - 一面作品牆，放這次瀏覽留下的作品，加上系統預設的圖庫。預設圖可以用程式生成原創圖案，數量多，每次隨機排列。
2. **提供圖片**：使用者上傳圖片，或從圖庫挑選。
3. **製版**
   - 選擇色數，系統自動分色，每一層都可以調整門檻。
   - 加入曬版、沖水的小動畫。
4. **欣賞版子**：完成的版子單獨展示，讓使用者好好看一下。
5. **選墨水**：把色卡排在一起試配色，也可以在調墨台上混色。混得不夠勻，會留下色紋。
6. **選媒材**：紙卡、帆布袋、T 恤、手帕等，以卡片呈現並附材質預覽。
7. **工作桌**
   - 固定好器材後，一層一層刷色。每刮完一層就掀框看結果。
   - 下一層要手動對位，網框是半透明的，搭配十字對位標記。錯位真正來自使用者之手。
   - 每層之間要等墨乾，可以乾等，或用吹風機加速。
8. **完成**：作品可以下載，也會放進作品牆。

## 開發階段

- **階段一：工作桌原型。** 單一 HTML 檔，只驗證刮印的手感好不好玩。
- **階段二：整理架構。** 拆成模組，決定正式的技術架構。
- **階段三：補上其他站。** 一次只做一站。
- **階段四：打磨。** 調整瑕疵參數、加入音效、處理手機版。

## 不做的事

- 3D 場景或擬物風格的道具
- 帳號、登入、後端
- 這份文件沒有提到的功能。若要新增，先提出來討論。
